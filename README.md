    > 情報交換用漢字符号―補助漢字
    > Code of the supplementary Japanese graphic character set for information interchange
    > - [:link:](https://webdesk.jsa.or.jp/books/W11M0090/index/?bunsyo_id=JIS+X+0212:1990)
